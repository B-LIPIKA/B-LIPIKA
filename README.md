### 💫 About Me

- 🔭 **Specialization:** Real-time **Computer Vision** pipelines and **IoT** integration with ESP8266 microcontrollers.
- 🌾 **Featured System:** Created **[AgriFlow](https://github.com/B-LIPIKA/Agriflow-)**, an automated smart irrigation network with remote pump actuation.
- 👁️ **Computer Vision:** Real-time face/object detection with distance estimation, intruder snapshot logging, and virtual air-writing.
- ⚡ **Hardware Interfacing:** Extracting edge contour data and streaming binary frames wirelessly to embedded chips.
- 🎯 **Goals:** Exploring edge AI deployment, low-latency vision pipelines, and intelligent automated devices.
